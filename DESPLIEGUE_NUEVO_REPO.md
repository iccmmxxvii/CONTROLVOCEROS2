# Despliegue en un repositorio nuevo

1. Crea un repositorio nuevo en GitHub.
2. Sube **el contenido de esta carpeta directamente a la raíz** del repositorio (no la carpeta contenedora).
3. Verifica que en la raíz queden `app.py`, `requirements.txt`, `VERSION`, `core/`, `pages/` y `data/`.
4. Verifica específicamente que exista `data/base/icc_estructura_12211.csv.gz`.
5. En Streamlit Community Cloud selecciona `app.py` como Main file path.
6. No necesitas Supabase para probar la base precargada y los reportes locales.
